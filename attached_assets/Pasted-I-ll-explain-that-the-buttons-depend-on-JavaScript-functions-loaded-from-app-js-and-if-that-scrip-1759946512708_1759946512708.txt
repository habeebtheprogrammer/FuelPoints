  If /app.js doesn’t load (404, wrong host, served from file://, etc.) or it
  stops running because of a script error, those functions never attach and the
  buttons feel dead. Check the browser console—you’ll typically see either:

  - GET <origin>/app.js 404 followed by Uncaught ReferenceError:
    showAddItemGroupModal is not defined, or
  - another error logged before the functions above are reached.

  Most often this happens when the page is opened from the Expo dev server
  (http://localhost:5000/admin) or straight off the filesystem. In that case
  every fetch in the admin points to the wrong origin, /app.js never loads, and
  none of the handlers get registered.

  Fix options:

  1. Serve the admin console from the Express backend (run npm run server or
     PORT=3000 npx tsx server/index.ts) and open it at that origin, e.g. http://
     localhost:3000/admin.
  2. If you need to hit it through another host/port, make sure that host
     proxies /app.js, /styles.css, and the /api/admin/* endpoints back to the
     Express server.

  Once /app.js is loading cleanly (no console errors), those buttons will work—
  the code behind them is already in place.
